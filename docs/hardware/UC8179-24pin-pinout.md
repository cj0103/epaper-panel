两份规格书描述的是**同一颗主控 UC8179 的同款 24pin FPC 玻璃**，针脚编号一一对应。

## 裸屏必须外配的硬件

这屏主控 UC8179 虽然有片内升压，但 **24pin FPC 上仍然要外部提供**：

| 项目 | 脚位 | 要求 |
|------|------|------|
| 逻辑/主电源 | 15、16（18 加电容） | 都是 **3.3V** |
| 地 | 17 | GND |
| 总线选择 | 8 | 接地 → 4 线 SPI；接高 → 3 线 9bit |
| 栅驱动供电 | **21 VGH / 23 VGL** | **外部升压电路输出**，各配等值滤波电容 |
| 电流采样 | 3 RESE | 采样电阻到 GND（HINK 参考电路：MOS + 肖特基 + 电感 + 采样电阻） |
| 栅极驱动使能 | 2 GDR | 外接 N-MOS |

所以**光有 6 根 SPI 信号线是不够的**，必须有带升压电路的驱动板。

## SPI 时序要点（规格书 6.3 节）

- **4 线 SPI**（BS1 = Low）：CSB / DC / SCLK / SDIN，每帧 8 bit，D7 先出
- **3 线 SPI**（BS1 = High）：CSB / SCLK / SDIN，**DC 脚接 GND**，每帧 9 bit，
  DC 位在**帧首位**（D/C → D7..D0）
- CSB 必须拉低才使能通信；BUSY 为低时不得发命令
- 仅支持写操作（Write-only）

## 与本项目的关系

- 本项目用的是**分立墨水屏转接板**：屏直插转接板的 24pin FPC 座，
  转接板自带升压电路 / 采样电阻 / 去耦电容，**S3 主板只出 6 根信号线**：
  `SCK=11 MOSI=10 CS=9 DC=8 RST=7 BUSY=6`
- 转接板把屏的 BS(8) 接地 → 4 线 SPI ✔
- iDevice 整合驱动板那套 24 针座网络与本表**对不上**（电源脚错位 + 上接/下接针序镜像），
  详见 `README.md` 的"已弃用"一节。
